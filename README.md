Quiz – Idées Reçues

Lien :
https://grdraphael.github.io/quizz-idees-recues/

Projet réalisé pour mettre en pratique les bases de HTML, CSS et surtout JavaScript.

L’application propose un quiz Vrai / Faux autour d’idées reçues scientifiques. Les questions sont générées dynamiquement et chaque réponse déclenche une explication ainsi qu’une mise à jour de l’interface.

Ce projet m’a permis de travailler la manipulation du DOM, la gestion des événements, la logique conditionnelle et l’organisation d’un petit projet front-end en JavaScript vanilla.
